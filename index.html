🔐 Authentication Architecture

Conceptual integration of OAuth and JWT authentication.

🌐

OAuth Login

OAuth allows users to authenticate using an external identity provider such as Google. The application does not need to directly handle the user's external password.

🎫

JWT Authentication

After successful authentication, a backend can issue a signed JSON Web Token. The client can send the token with requests to protected resources.

🔄

Dashboard Flow

Login → Authentication → Token → Role Verification → Authorized Dashboard → Protected Resources.
