# AI Intelligent Cognitive Alarm Platform

## Module 1 – Authentication & Role-Based Access Control

This repository contains the implementation of **Module 1** for the AI Intelligent Cognitive Alarm Platform. The module focuses on secure user authentication, authorization, and role-based access control.

## Features

- User Registration & Login
- JWT Authentication
- Google OAuth Login
- Role-Based Access Control (RBAC)
- Protected Routes
- PostgreSQL Database Integration
- User, Wellness Coach, and Admin Dashboards

## Tech Stack

**Frontend**
- React (Vite)
- React Router
- Axios

**Backend**
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication
- OAuth2
